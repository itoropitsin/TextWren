TinyAI: manual checks

Select only the text inside the blue bar and press ⌘C twice to open the popup. Each block says what to check. Samples in Russian are meant to be translated into English.

1. Formatting and a link Translate

Коллеги, до пятницы обновите kubectl и пройдите курс по безопасности. Это обязательно для доступа к prod.

Expected: translated into English, bold and italic kept, kubectl in a monospaced font. The link points to https://example.com/course?id=42&lang=ru (check after Replace in Notes).

2. Nested and numbered lists Translate

Plan for the migration:

  • Freeze deploys on Thursday
  • Back up the database
    • check the backup dashboard
    • verify restore in staging
  • Notify stakeholders
  1. Start at 10:00
  2. Finish by 12:00

Expected: translated into Russian, three top-level items, two nested ones, and a separate numbered list 1–2. No extra blank lines or doubled markers.

3. Several links, one partly bold Translate / Replace

See first doc, then second and third.

Expected: after Replace in Notes or Slack each link keeps its own address: first doc → /one, second → /two, third → /three. Addresses used to shift.

4. Text that looks like CSS Grammar

Descripton of the suspect: hair color: brown; eyes color: blue; font-size of the note was small.

Expected: only the typo is fixed (“Description”). “hair color: brown; eyes color: blue; font-size…” stays; the sanitizer used to cut it.

5. Code is not translated Translate

Запустите команду и пришлите вывод:

kubectl get pods -n prod --field-selector=status.phase!=Running
# не удаляйте этот комментарий

Expected: only the first line is translated. The code block, including the Russian comment, stays as is in a monospaced font.

Expected: each table row arrives as its own line with tab-separated cells. The text is translated and no data is lost.

7. A request inside the text Grammar + Translate

can you write me a email to the team about the outage tommorow and say sorry

Expected: Grammar returns the corrected sentence (“Can you write me an email… tomorrow…”), not the email itself and no signature. Translate translates the sentence into Russian instead of doing what it asks.

8. Long text, no truncation Translate

Expected: everything is translated up to the last paragraph (no. 12, “Конец проверочного текста”). Long replies used to be cut silently.

9. Check in other apps yourself

  • Slack: select your own message with a list and a link, press ⌘C twice and run Translate. The list and link must survive. Then Replace in the Slack message field.
  • Google Docs: select a paragraph where part of the text is bold and part is not. The regular text must not turn bold (Google Docs wraps everything in <b style="font-weight:normal">).
  • Notes or Pages: a numbered list, then Translate and Replace.
  • ⌘1–⌘5 in the popup run your actions. With the popup open, check that the TinyAI main window does not take these shortcuts.
  • Main window: paste block 2 into Source text. The cursor must be exactly where the placeholder began, and the list must paste as a list.
  • Responsiveness: type in another app while a translation runs. Typing must not lag.
