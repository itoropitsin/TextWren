TinyAI: ручная проверка

Выделяйте текст внутри синей полосы (только его) и дважды нажимайте ⌘C, чтобы открыть popup. В описании каждого блока сказано, что проверить.

1. Форматирование и ссылка Translate

Коллеги, до пятницы обновите kubectl и пройдите курс по безопасности. Это обязательно для доступа к prod.

Ожидается: перевод на английский, выделение жирным и курсивом сохранено, kubectl моноширинным шрифтом. Ссылка ведёт на https://example.com/course?id=42&lang=ru (проверьте после Replace в Notes).

2. Вложенные и нумерованные списки Translate

Plan for the migration:

  • Freeze deploys on Thursday
  • Back up the database
    • check the backup dashboard
    • verify restore in staging
  • Notify stakeholders
  1. Start at 10:00
  2. Finish by 12:00

Ожидается: перевод на русский, три пункта верхнего уровня, два вложенных, отдельный нумерованный список 1–2. Лишних пустых строк и двойных маркеров нет.

3. Много ссылок, одна частично жирная Translate / Replace

See first doc, then second and third.

Ожидается: после Replace в Notes или Slack каждая ссылка ведёт на свой адрес: first doc → /one, second → /two, third → /three. Раньше адреса могли сдвигаться.

4. Текст, похожий на CSS Grammar

Descripton of the suspect: hair color: brown; eyes color: blue; font-size of the note was small.

Ожидается: исправлена только опечатка («Description»). Слова «hair color: brown; eyes color: blue; font-size…» на месте, раньше санитайзер мог их вырезать.

5. Код не переводится Translate

Запустите команду и пришлите вывод:

kubectl get pods -n prod --field-selector=status.phase!=Running
# не удаляйте этот комментарий

Ожидается: переведена только первая строка. Блок кода, включая русский комментарий, остался как есть и отображается моноширинным шрифтом.

6. Таблица Translate

СервисВладелецСтатус
VPNАннаРаботает
ПочтаПедроПлановые работы

Ожидается: строки таблицы приходят отдельными строками, ячейки разделены табуляцией. Текст переведён, данные не потеряны.

7. Просьба внутри текста Grammar + Translate

can you write me a email to the team about the outage tommorow and say sorry

Ожидается: Grammar выдаёт исправленную фразу («Can you write me an email… tomorrow…»), а не само письмо и без подписи. Translate переводит фразу на русский, а не выполняет её.

8. Длинный текст, проверка на обрезание Translate

Ожидается: переведено всё до последнего абзаца (№ 12 «Конец проверочного текста»). Раньше длинные ответы молча обрезались.

9. Проверьте сами в других приложениях

  • Slack: выделите своё сообщение со списком и ссылкой, дважды нажмите ⌘C и сделайте Translate. Список и ссылка должны сохраниться. Затем Replace в поле ввода Slack.
  • Google Docs: выделите абзац, где часть текста жирная, а часть обычная. Обычный текст не должен стать жирным (Google Docs оборачивает всё в <b style="font-weight:normal">).
  • Notes или Pages: нумерованный список, затем Translate и Replace.
  • ⌘1–⌘5 в popup запускают ваши действия. При открытом popup проверьте, что главное окно TinyAI не перехватывает эти сочетания.
  • Главное окно: вставьте блок 2 в Source text. Курсор должен стоять ровно там, где начиналась подсказка, а список вставиться списком.
  • Отзывчивость: во время перевода печатайте в другом приложении. Набор не должен тормозить.
